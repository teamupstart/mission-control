Voice settings panel

Where the operator sets the system-wide mute hotkey, auto-mute during calls, the cancel window before routing and auto-submit, and what happens when routing is unsure (ask aloud, or show on screen). The panel also points at where spoken names are set (a resident's reference name on its profile, a session's call sign in dispatch Advanced) and at the Recently heard list.

Fixed in every variant: the Voice preview flag itself stays in the Feature flags list like every preview, the five settings and their defaults are the spec's, and the hotkey uses the capture control Keyboard settings already has. What varies is what the panel leads with and where it lives. Each variant shows the normal panel, the hotkey being captured and refused, and voice unavailable. ⌃⌥M is an example chord only.

Names can still be reviewed and fixed while voice is not listening.

  • Answers the question the spec makes most likely: "who can I talk to, and what do I call them?", and shows every name warning in one place instead of only at the moment a name is typed.
  • The roster is a live view of the daemon's name registry, so the panel needs that registry on the wire (a snapshot field and an event), not only settings in app_config.
  • The same table is the roster the recognizer is primed with and the small model is given, so what the operator sees is what routing uses.
  • Names are still edited elsewhere (profile, dispatch). A read-only table that looks editable invites clicks that only navigate away.
