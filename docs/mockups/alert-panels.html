Alert panel mockups

Six directions for the bell popover, from a drop-in refinement to a rethink of what the panel is for. All six use the app's real tokens and its existing pill-switch language (.pal-switch), so what you see is what it would look like shipped. The switches are live - click them; B, C and D recompute their status line from the actual state, including the "nothing can reach you" case AlertBar.tsx currently spells out in a paragraph.

A

Refined rows

Same three controls, same order. Switches instead of raw checkboxes, a one-line description per row so the hint paragraph stops carrying the explanation, and a rule separating the two local prefs from away mode - which is server state and survives the tab closing. Lowest-risk change.

E

Per-kind routing

Exposes the alert engine directly: one row per AlertKind, with paired dots where a kind can emit either severity. Most control, most surface; needs a real appetite for per-kind prefs the server doesn't store yet.

F

Live inbox

The biggest rethink: the bell opens the alerts, not the alert settings. What's blocked on you now, then what's buffered, each row deep-linking to its session; the three prefs shrink to a footer. This adds a count to the bell, while actionable counts live elsewhere in the topbar today, and makes clicking the new count answer the question it raises.

Reading these

  • A and B are drop-in replacements - same state, same routes, only AlertBar.tsx and a CSS section change.
  • C and D need the away buffer's count and elapsed time on the wire; the daemon already holds both (away-buffer.ts, AwayConfig.awaySince).
  • E needs a new per-kind preference store - the alert engine emits the kinds already, nothing persists a routing choice per kind.
  • F needs live alerts kept in client state rather than fired and forgotten, plus the deep-link each row implies. There is already an AttentionInbox component to borrow rows from.
  • Severity dots in E follow AlertSeverity: amber = attention (blocked on you, always delivered), grey = info (digest material).
