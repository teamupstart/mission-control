Vertical space and glanceability. Roughly half the height of today's strip, and it survives the topbar's responsive ladder by shedding the trailing secondary figures, then the chips' meters, before it ever wraps.

Costs

Code it touches

FleetStrip.tsx only, plus the .fleet-strip section of styles.css. No new server data. A window token has to come off the harness rather than the label string.
