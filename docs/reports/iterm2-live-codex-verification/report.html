Defects fixed in the worktree

  • False negative after a successful launch. The iTerm2 adapter no longer reads current tab, current session, and id from the object returned by create window. The launched shell writes its iTerm session identity into a private temporary marker. A valid marker proves launch success even if the Apple Event times out. [1]
  • Identity mismatch. iTerm2 exports ITERM_SESSION_ID as wNtNpN:UUID, while AppleScript returns the bare GUID. Mission Control now removes only the documented mutable positional prefix and uses the GUID for discovery, launch targeting, and hook binding. [2]
  • Bounded cleanup. Spawn markers use a private temporary directory, are polled for one bounded second, and are always removed.
