The usage bar, five ways

Same fleet, same moment, five shapes. Real tokens from src/web/styles.css, real figures from the screenshot ($552.23 today, $5.61/hr, 856M tokens, $39.44/PR), and the three windows the strip is reporting on: Claude 5-hr at 31% (clears), Claude 7-day at 91% (~6h 51m of runway), Codex 1-week at 19% (clears). Each is drawn in place, between the real topbar and the board, so its vertical cost is honest - and every height quoted below is measured off the rendered page, against today's 105px.

Only the usage row is under review. Everything above it is drawn as flat grey placeholders, because the topbar's own controls are not part of this change; the board columns beneath are today's, for scale.

What is wrong with today's bar, in one line: four figures at equal weight, and the one forward-looking fact on the strip - a 7-day window that runs out this afternoon - is the smallest thing on it, three-quarters of the way to the right edge, behind the phrase "limit runway" written out three times.

Optimises for

Vertical space and glanceability. Roughly half the height of today's strip, and it survives the topbar's responsive ladder by shedding the trailing secondary figures, then the chips' meters, before it ever wraps.

Costs

No room for labels, so 5H / 7D / 1W have to be learned once, and the window's reset time moves into the tooltip. Least room to grow if a fourth window appears.

Code it touches

4 Ledger 136px · 31px more

The instrument-panel reading. Two hairline-ruled tables, right-aligned mono figures, no tint and no panel accent. Every window is a row, so a fourth harness or a fifth window costs one line and reflows nothing. Severity is a leading flag plus a coloured figure, never a coloured surface - so the bar stays quiet until something is actually wrong, and this doubles as the accessible table view of the same data.
