Make the agent feel like a live process.

Three ways to steer a coding session without falling back to a generic chat window. The first two feel native to a terminal. The third spends that familiarity on a quieter reading experience for long-running work.

01 · TERMINAL

Native PTY

One continuous prompt and output stream. Human instructions look executable, agent prose reads as stdout, and tool runs fold into command records. No bubbles.

02 · TERMINAL

Duplex Console

A split terminal keeps the agent's narrative in the main channel and transcript-observed tool activity in a sideband. It ends in a compact multiplexer status line.

03 · READING

Operator Log

A chronological field log treats your messages as directives and the agent's work as a readable report. Session purpose and position stay pinned in a context rail.
