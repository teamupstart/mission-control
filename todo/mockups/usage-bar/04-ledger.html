4. Ledger

The instrument-panel reading. Two hairline-ruled tables, right-aligned mono figures, no tint and no panel accent. Every window is a row, so a fourth harness or a fifth window costs one line and reflows nothing. Severity is a leading flag plus a coloured figure, never a coloured surface - so the bar stays quiet until something is actually wrong, and this doubles as the accessible table view of the same data.

Optimises for

Precision and growth. Five columns of aligned figures read faster than five tooltips, the percentage stops being tooltip-only, and N windows is a map over rows with no layout to re-tune.

Costs

Deliberately unglamorous, and the least glanceable at arm's length - it rewards reading rather than seeing. Wants a real column ruler, so it is the variant most likely to look cramped on a 13" screen.

Code it touches

FleetStrip.tsx and its stylesheet section. No new data. Also the cheapest to make accessible: it is already a table.

Narrow 940px laptop, or a window at half width

Same bar in the width where the topbar's responsive ladder starts shedding ink. What wraps first, and whether it still reads, is part of the choice.
