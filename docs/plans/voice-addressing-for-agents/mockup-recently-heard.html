Recently heard

A short, in-memory list of recent utterances and why each did or did not route, including rejected near-miss names, for debugging misses. It is never written to disk and is gone when Mission Control quits. Audio is never kept.

Fixed in every variant: the same six utterances (exact name, phonetic match, small-model decision, first-word name without a pause, rejected near miss, cancelled in the cancel window), each with how long ago, the words heard, the outcome and the reason in plain words; a Clear control; the privacy line; and an empty state. Nothing is heard while voice is muted, so muted time leaves no rows. What varies is where the list lives and how much of the routing detail it shows.

One line per row: either the words or the reason, never both.
  • One click from any app, and it sits with the listening state, so "did it hear me?" and "is it listening?" are answered in the same place.
  • The tray is a native menu built by Menu.buildFromTemplate in src/main/tray.ts. A popover is a new anchored window in the shell; the native submenu in state 3 avoids that but fits one line per row.
  • The shell already polls the daemon for the tray's counts, so the ring buffer can ride the same poll.
  • Outside the dashboard, so Playwright cannot see it. It needs Electron tests, and there is no room for a filter or a long reason.

  • An exact first-word name routes without a pause. An amber name identifies a rejected near miss; a pause observation never blocks an exact match.
  • Reads like a debugger. For the operator who only wants to know whether Steve got the message, five columns is a lot of table.
  • Maps one to one onto what the router already knows per utterance, so the ring buffer's row shape and the table's columns are the same thing.
  • Needs about 1,000px of width, so it only fits a dialog or a full settings pane, never the tray or a drawer.
