Personas, Actions and Commands

Three approaches to each of the three Library detail screens - nine mockups. They share a spine so they can be judged as one decision, and each is customised for what its screen is actually for: a Persona is writing, an Action is a contract, a Command is a resolution. Pick one letter and it applies to all three.

The bug that started this, confirmed in the running app

Escape on #/library/personas/…, #/library/actions/… or #/library/commands/… does nothing at all - it is not being swallowed by a competing handler, the behaviour is simply absent. App's global keydown does its page-shortcut work and then hits if (route.page !== "fleet") return; (App.tsx:1531), which sits above the entire Escape ladder. No component under src/web/library/, PersonaLibrary, SessionActionLibrary or CommandLibrary registers one either.

And there is no visible way out: none of the four authoring surfaces renders a back button, a breadcrumb, or a close control. The only exit is clicking the topbar Library segment - which is already painted aria-current, so it reads as the page you are on. The w chord is blocked by the typing guard, and the CodeMirror pane that dominates Personas and Actions is contenteditable, so it is blocked exactly where the screen is biggest.

That last detail is the trap in the obvious fix. SettingsPage.tsx:412 already has the page-level Escape to copy, but it bails on closest("input, textarea, select, [contenteditable='true']") - copied verbatim it would be dead in the pane that fills the screen. A Library Escape needs an explicit rule for the editor host: first Escape leaves the editor, second leaves the page. Every approach below assumes that ladder.

the three approaches

A Rail

Keep the two-pane workbench, fix its grammar. A permanent ← Library row carrying esc, Built-in / Yours groups, one promoted verb plus an overflow menu, and the metadata block collapsed into property chips.

Persona
chips for provider and model, quiet when inherited
Action
a contract line under the chips, written as one sentence
Command
default and overrides as one table, add row visibly an add row

B Focus

Drop the rail on the detail. Centred column, breadcrumb plus a labelled Close, and everything that is not the payload behind one bar that summarises itself while shut. Prev/next replaces the list.

Persona
the guidance is the page; ~410px more writing width
Action
the contract as a sentence you fill in, above the instruction
Command
a resolver: pick a repo, see which rule wins and why

C Sheet

The card wall never unmounts; the detail opens over it behind the app's own rgba(4,6,9,.72) backdrop. Escape, Close and the backdrop all dismiss, and none of it needs teaching. Content is tabbed.

Persona
Guidance / Routing / Provenance - drift finally gets a home
Action
the contract drawn as the chain it is at run time
Command
all four gates as one repository × slot matrix
