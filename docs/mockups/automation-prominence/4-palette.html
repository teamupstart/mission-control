01Findability without chrome. The palette indexes what people actually hunt for - the builder, a live run, a Persona, an amber decision - not just settings controls. Every row shows kind + live state, so search doubles as a status check.
02The pulse teaches by summary. The popover rows each carry the purpose sentence beside the live fact, so the first encounter with "Ensembles" explains itself. Purple is the right color: it is already the app's machinery tone (Foreman, cost), deliberately outside the fleet's state tones.
03Ships in two small PRs. Extend the existing settings-search index with workflow/persona/ensemble/mission providers; add one pulse segment + popover. No routes move, no page changes, fully keyboard-native.
04Limit: prominence is still opt-in - you see automation when you ask. This approach fixes discovery and reach, not the deeper "hidden by default" complaint. Best paired with approach 1 or 3.
