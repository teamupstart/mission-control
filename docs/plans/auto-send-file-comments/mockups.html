4. How it works end to end

One session, three comments written while the agent works through them. The agent never has more than one comment outstanding, exactly as today.

1. Send on line 84

Nothing is out, so it goes to the outbox now and on to the agent at the next idle gap. The marker turns amber.

  1. 1plan.md:84sent
2. Send on line 112, then app.ts:40

The hints read "Waits behind 1 comment", then "Waits behind 2 comments". Both queue; you can still reorder or edit them.

  1. 1plan.md:84sent
  2. 2plan.md:112queued
  3. 3src/app.ts:40queued
3. The agent answers MC-a41f

Through the reply tool, or the grace window runs out. Line 84's marker turns green, and line 112 goes next with no click.

  1. 1plan.md:112sent
  2. 2src/app.ts:40queued
4. Queue drains

The review returns to idle, the count resets, and the next Send goes straight out again. Replying on an answered thread re-enters the queue the same way.

Nothing waiting.
