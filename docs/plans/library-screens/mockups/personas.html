Personas

Three approaches to the screen behind a Persona card, each fixing the same four faults. There is no way out - App.tsx:1531 returns before the Escape ladder for any page that is not the fleet, and none of the four authoring surfaces renders a back control, so the only exit is a topbar chip already styled as the current page. You pick the same thing twice, once from the card wall and again from a rail that repeats it. Roughly 330px of chrome sits above the markdown that is the actual asset. And Save is one of four equal-weight text links, next to Archive. All three approaches also add the fact the screen is missing entirely: which workflows are pointing at this Persona right now.

A

Rail

evolve the workbench · smallest diff

The two-pane shape stays, because reading one reviewer's standards while editing another's is a real thing people do here. Its grammar changes. The rail gains a permanent ← Library row at the top, so the exit is first in reading order and never scrolls away, and it carries esc as its own label so the keystroke is taught rather than assumed. Assets group into Built-in and Yours, so the four shipped Personas stop reading as things you wrote. The flat four-link header becomes one promoted verb plus an overflow menu. The five-field metadata block collapses into property chips that open popovers, and inherited values render quiet while overridden values render solid - so what this Persona actually changes is legible without opening anything.

smallest change to ship exit always visible editor gains ~215px of height keeps side-by-side comparison two lists still describe one choice

B

Focus

the guidance is the page

A Persona is a piece of writing - 3,151 bytes of standards that a reviewer gates on. This approach treats it that way. The rail goes; the column centres at a readable measure; the markdown starts about 190px from the top instead of 330px. Everything that is not the writing collapses into one properties bar that answers its own question while shut - you read "Codex · gpt-5.6-terra · inherited" without opening it, and you open it on the rare occasion you are changing routing rather than standards. The rail's one genuinely useful job, moving between Personas, becomes a footer pager, so [ and ] still walk the set without a permanent 268px tax on the writing surface.

editor gains ~410px of width and ~140px of height three labelled exits, none of them a bare glyph reads as a document, not a form no side-by-side comparison largest departure from what ships

C

Sheet

the Library never leaves

The premise of the bug is that people press Escape on things that look like they are on top of something else. So make that true rather than teaching around it. The card wall stays mounted and visible behind a scrim, and a Persona opens as a sheet over it. Escape closes it, the backdrop closes it, the Close button closes it, and none of that needs a hint. Because a sheet is a bounded surface rather than a page, its content can be tabbed - Guidance for the writing, Routing for provider and model, Provenance for import path, content hash and upstream drift. That last one matters: drift is currently a banner that only appears when something is already wrong, and this is the only approach of the three that gives it a permanent home.

Escape is self-evident, not learned you never lose your place in the Library provenance and drift get a real home smallest writing surface of the three needs a focus trap, and a dirty gate on every dismiss path
