Indexed directories for repository detection

Today the daemon scans exactly ~/workspace, and the only way to change that is an environment variable set before launch. This adds a Repositories category to Settings holding the list of directories that are walked, seeded with ~/workspace, ~/code, ~/dev and ~/upstart, any of which can be removed. Three takes below. A is the adopted direction; B and C are kept for the record.

A

Directory rows adopted

One row per directory carrying its path, whether it is a seeded default, and what the daemon actually found there - 14 repositories, not found, not a directory - with Remove on the row. An Add field, Restore defaults, and Rescan now beneath. Four screens: as shipped, after edits with a refused path, under an environment override, and emptied.
