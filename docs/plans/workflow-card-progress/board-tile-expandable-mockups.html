Three ways to put workflow progress directly into the Board tile. Each stays compact enough for fleet triage, then expands in place to reveal the full Stage Ladder and its actions. The examples use the exact “Review changes” state from the current UI.

Interaction thesis “Review changes” becomes a disclosure state. The full Runs page remains available as “Open run” inside the expanded ladder.
