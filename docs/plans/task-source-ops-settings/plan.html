Task source operations overview in Settings

Goal

Replace the one-large-card-per-source Task sources panel with the operations-first Settings layout selected from mockup #3. It must make dozens of configured sources scannable by health, type and schedule, while retaining access to every existing per-source setting and safety action.

Scope

  1. Add an operations summary and compact filterable source rows.
  2. Show the existing source editor only for a selected source.
  3. Provide health filters, text search and type filtering.
  4. Keep every existing source action and Add a source.
  5. Extend static render tests.

UI behavior

The default pane is a directory with summary cards, an attention callout, filters and compact rows. Selecting a row replaces it with the existing source editor and an “All task sources” back control. Add source retains the current selector and repository chooser; this change does not implement Jira or Slack connectors.

Data flow

TaskSourcesView (sources + status)
        ↓
TaskSourcesPanel → Operations directory → Selected source editor
        ↓                     ↓
existing TaskSourcesState callbacks → existing task-source routes

Verification

  • Update panel static-render tests.
  • Run focused tests, typecheck and project test/lint commands.
  • Commit on a feature branch and use the no-mistakes PR workflow.
