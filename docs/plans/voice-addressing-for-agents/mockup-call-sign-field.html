Call sign field and name validation

A session becomes addressable by voice when it is given a short spoken name, a call sign, in the dispatch form's existing Advanced box beside Persona and Plan storage. A resident is addressed by its profile name unless an optional reference name is set on the profile. When a name is chosen Mission Control validates it and warns, but does not block, when it is a common English word, phonetically close to another agent's name, a very short single syllable, or a control word.

Fixed in every variant: the field sits in the real Advanced fold (dispatch-more), the collapsed summary names the call sign, the warning is amber and never red, and Dispatch stays enabled. What varies is how the warning is explained and how much help the field gives in choosing a better name. Each variant shows the fold open with no name, a good name, two different warnings, the fold collapsed again, and the same pattern on a resident profile's reference name.

Identity

Residents are addressed by their profile name unless a reference name is set.

  • Teaches the feature where the name is chosen: the operator reads the exact sentence they will say, which is the spec's "teach in place" goal.
  • A four-step meter implies a score the validator does not have. The spec defines four yes or no rules, so the steps would be invented.
  • The preview doubles as the field's voice hint, so no separate hint line is needed for a good name.
  • Two extra rows under one optional field make the Advanced box noticeably taller than Persona and Plan storage beside it.
