Implementation plan

Conductor SDK launch runtime

Add an explicit choice between the current terminal-hosted Engineer launch and a managed Claude Agent SDK session that invokes /engineer <idea> directly.

Answer first

The SDK can replace Mission Control's Engineer terminal.

tmux is not required by Conductor's planning logic. Today it supplies interactive stdin, persistence, attachment, and the task-to-run join for conduct-ts engineer. Mission Control can supply the host through its existing Claude SDK supervisor if it preserves provider-run identity and completion semantics.

Boundary

Not tmux-free end to end

Conductor's separate background build daemon still uses its own tmux supervisor. This plan changes only the interactive Engineer host.

Proposed ownership flow

Runtime contract

Terminal

Keep conduct-ts engineer --idea, a unique terminal home, attachable stdin, and legacy home/worktree correlation.

Claude Agent SDK

Start Claude through SdkSupervisor with the task id and exact /engineer <idea> turn one. Record its session id and no home.

Identity

The provider adapter copies Conductor's canonical 50-character slug rule. Duplicate projected keys are refused before launch.

Completion

Neither terminal exit nor SDK idleness completes the task. The provider's processed projection remains authoritative.

Approved rollout decisions

1
Claude Agent SDK ships as the default

Old config blobs and fresh installations parse to claude-sdk. Terminal remains an explicit compatibility selection.

2
Selected-runtime failures stay visible

Mission Control records the launch error and does not silently fall back to Terminal. Retry remains available after configuration changes.

Verification bar

  1. Schema and route round-trip both runtime values and upgrade old blobs by default.
  2. Unit tests pin slug identity, duplicate refusal, both launch shapes, restart recovery, host loss, provider completion, and old terminal compatibility.
  3. Playwright selects and persists SDK, dispatches to an SDK session with no home, then switches back and proves the terminal path still launches a home.
  4. Run typecheck, lint, unit suite, build, smoke, and the end-to-end suite.
