3/4The line: purpose through position

The boldest reframe: the fleet gets a permanent strip that draws the life of a task as a literal line - intake, backlog, working, review, decide, shipped. Workflows stop being a page you visit; they ARE the review stage. Ensembles ARE the decide stage. Missions and sources ARE intake. Each stage is live (counts, the one sentence that matters) and clicking it opens a drawer - shown here on Decide, where an ensemble is waiting on you. The board continues underneath, untouched.

01The diagram is the navigation. Nobody has to learn what an ensemble is for - it sits between Working and Shipped, labeled Decide, wearing an amber count when it needs you. Position explains purpose better than copy can.
02Triage finally sees automation. Today the Sitrep, backlog and command bar are blind to workflows and ensembles. The line puts both into the operator's every-glance path without touching the board below it.
03Drawers, not pages. Each stage opens in place: Intake shows missions + sources, Review shows run ladders, Decide shows the dossier condensed to one decision. Full pages remain one click deeper for authoring.
04Cost: the most opinionated of the four - it asserts that work flows left to right, spends ~90px of height on every layout, and needs server-side folds (a per-stage summary event) so the strip never recomputes fleet state in the browser.
