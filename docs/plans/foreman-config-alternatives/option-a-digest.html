Why this one

  • Shortest at rest without deleting a single control or sentence.
  • Config doubles as status. Six lines answer "what is Foreman set to", which is the actual reason this panel gets opened.
  • No new page, no new route. Every data-anchor deep link and every settings-search hit still resolves.
  • Scales. A tenth setting adds 30px, not 300px.

What it costs

  • One click to edit. Fine for set-once config; mildly annoying if you are tuning the cheap tier repeatedly.
  • Expanding shifts layout. The editor is capped at 46vh and scrolls, which is a fix for the symptom - on a short window the ledger still moves under you.
  • A digest line must not lie. Each row needs a formatter that reports the RESOLVED value, including when the field is empty and an env var or the provider default is what is actually in force. That is real work, and getting it wrong is worse than the long column.
  • Two rows summarise four and three fields. "Terra ×2 · Luna ×2" is honest but it is a compression, and someone will eventually want the roles named.
