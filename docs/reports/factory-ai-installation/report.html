Installing Factory AI at Upstart

Start with access, not the installer. Factory is an EARLY TESTING coding-agent option with limited access for agent power users. Once provisioned, the supported local path is to sign in with the Upstart account, install the Droid CLI, and run droid from a repository.

Recommended path

Use Factory only if you have a concrete power-user need. Upstart's AI Tools Overview says Factory is model-agnostic but is not the recommended path. Claude and ChatGPT/Codex are the recommended tools for core development. Do not install Factory merely to obtain a default coding agent.
Request or confirm access.

Use go/access and search for the Factory: User entitlement. The entitlement is enabled and prior grants are recorded as Access Requests. Include a short, specific agent-power-user use case. Do not request Manager or Owner access for ordinary development.

Sign in to Factory with your Upstart identity.

After access is provisioned, open app.factory.ai and complete sign-in. This is the checkpoint that confirms the entitlement is effective before changing your local machine.

Install a verified Droid binary.

Pin the version and download both the binary and Factory's SHA-256 file. For example, set VERSION=0.174.0, PLATFORM=darwin or linux, and ARCH=arm64 or x64, then set BASE_URL="https://downloads.factory.ai/factory-cli/releases/${VERSION}/${PLATFORM}/${ARCH}". Download "${BASE_URL}/droid" and "${BASE_URL}/droid.sha256" with curl -fsSLO. Before chmod +x droid or moving it to your PATH, verify it with echo "$(awk '{print $1}' droid.sha256) droid" | shasum -a 256 -c - on macOS, or replace shasum -a 256 -c - with sha256sum --check on Linux. Stop and install a checksum tool if neither command is available. Do not pipe a remote installer directly into a shell.

Verify in a repository.

Change into a local Git checkout and launch droid. Complete browser login if prompted. Start with a narrow, reviewable task and keep the default approval flow.

Add an editor integration only if useful.

For VS Code-family editors, Droid can offer the extension from the integrated terminal. For JetBrains, Factory's current documentation supports installation through AI Assistant's ACP registry. The terminal path works in any editor, so an IDE plugin is optional.

Usage and escalation

  • The current Factory monthly limit is $2,520 (200M FST), on a calendar-month basis. Check usage at Factory Settings - Usage.
  • For a limit increase, the published prerequisites include using the Codex allocation first, being within $500 of the limit, a specific project, and readiness to share work at the monthly guild meeting. Factory and Cursor increases use the published Google form; the source says to contact @ai_acceleration in #ai-acceleration if no decision arrives within one business day.
  • Do not store Factory API keys in a repository. Factory's CLI reference says API keys belong in an environment variable or secure secret-management system. An interactive browser login is enough for the initial local setup.
