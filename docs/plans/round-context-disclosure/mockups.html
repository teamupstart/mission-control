Round context without the banners

A run scrubbed onto an earlier round prints two full-width amber panels above the pipeline. Between them they say four things, three of which the scrubber directly above them has already said, and they cost roughly a fifth of the visible run detail before the pipeline starts. These are four ways to keep every sentence and put it behind a click.

Every mockup below is live: click the disclosure in each and it opens. All five use the product's own stylesheet and the product's own markup, so what renders here is what renders in the app. The run shown is a four-stage review parked on round 2, evidence 2, while round 3 is the live one.

Side by side

What each one trades

Option Rows above the pipeline Snapshot state visible without clicking Announced to a screen reader Survives a long run Room for the next sentence

A - context line 1 line Yes Yes Fixed height Popover grows, line does not
B - chip mark None Only as the LIVE mark elsewhere No Fixed height Per-chip popover only
C - scrubber pills None, until the scrubber wraps Yes, as two words Only if the pill group is a live region Wraps past ~6 rounds One more pill each time
D - about panel 1 heading row Only as the LIVE mark elsewhere No Fixed height Another row in one panel
Recommendation
A, with B's LIVE mark on the live round tile. A keeps the one thing a banner is genuinely good at, a state that is announced and cannot be missed, while dropping it from three lines to one and from alarm amber to muted text. B's mark is nearly free and answers which round is live positively, which is the question a reader actually has once they know they are not on it. D is the better shape if more per-round explanation is coming; it can be layered on later without undoing A.
Not mocked
Dropping the sentences into the existing chip tooltips alone. They are already there, and a hover-only fact is unreachable on a touch device and invisible to anyone who does not hover. That is what makes a click target the ask rather than a tooltip.
