Answering a question card by voice

With Steve's request_input card open on screen, "Steve, option B" or "reply, Postgres" ticks the matching option where the operator can see it, and Submit counts down using the same cancel window as routing. "Cancel" stops it. "No, A" switches the choice and restarts the countdown. A reply that matches no option goes into the card's text box as a written answer and counts down the same way. With the cancel window turned off, it submits at once.

Fixed in every variant: the real card (ReviewCard and DecisionForm, in an inbox row headed by the agent's display name in its board colour), the cancel window's length, and blue for anything voice did, the colour the human already has in a transcript. Every variant also prints a letter on each option, because the hint says "option B" and the card today prints none. What varies is where the countdown lives and how much of the card it takes over. Each variant shows four moments: at rest, ticked by voice, switched with "no, A", and a reply that matches no option.
